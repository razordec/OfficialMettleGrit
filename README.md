## 🚀 Getting Started

### Prerequisites

- [ ] A pair of flat shoes (`>=1`, running shoes deprecated for lifting)
- [ ] A water bottle (`min: 1L`)
- [ ] Willingness to be bad at something new

### Installation

# 1. Claim your trial
git clone https://www.mettlegritfitness.com/free-week.git ~/your-transformation

# 2. Book an onboarding session
mettle onboard --coach=auto --goal="whatever-you-want"

# 3. Run your first workout
mettle run --program=foundations --intensity=RPE6

🤝 Contributing
Progress here is open source by culture.

Fork your limits — pick one thing that scares you.
Branch small: add weight, a rep, or ten seconds.
Commit consistently. Daily beats heroic.
Review others kindly. Spot someone. Cheer a PR.
Merge into the community: train partners > solo grind.
New to lifting? Every regular was once the person who couldn't find the squat rack.

❓ FAQ
Do I need to be fit to join? No. You need to be unfit enough to still be honest about it. That's the entry requirement.

Will I get injured? Load managed with coaching scales technique-first. Injuries come from ego, not barbells.

Is there a contract? Month-to-month. Leaving should be a choice, not a lawsuit.

Can I just use the machines? Absolutely. Not everyone wants to snatch. All paths count.
